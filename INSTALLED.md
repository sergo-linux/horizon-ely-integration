# Использование с уже установленным Horizon

Этот режим избавляет пользователя от локальной сборки Rust. Нужен готовый
артефакт **этого пакета** для своей ОС: два бинарных файла, `BUNDLE.json`,
`installed.py`, инструкция и лицензии. Обычные официальные бинарные файлы
и старый архив Elyhorizon установщиком не принимаются.

Это установка отдельной сборки рядом с существующей. Сам установленный `.exe`
или `.app` не патчится. Скрипт копирует одну уже подготовленную версию ресурсов
в новый каталог и создаёт запуск новой пары программ. Оригинальные аккаунты,
конфигурации и миры не перезаписываются. Для игры появится отдельная папка миров.
Копия ресурсов занимает дополнительное место; общие junction/symlink не создаются.

## Где взять готовую сборку

В репозитории откройте Actions → **Experimental native builds** → Run workflow.
После успешной сборки скачайте артефакт `horizon-ely-experimental-windows-latest`
(либо Linux/macOS) и распакуйте ZIP. Если сборка не завершилась успешно или
артефакта нет, готовой установки пока нет. Зелёный `Check patch package`
подтверждает тесты Python и применение diff, а не нативную компиляцию.

Workflow можно запускать без Ely.by client ID: тогда соберутся локальные
профили, а кнопки входа Ely.by не будет. Для настоящего входа перед сборкой
нужно настроить собственный совместимый `HORIZON_ELY_CLIENT_ID`.
Проверка device-code flow с Ely.by остаётся отдельным обязательным шагом.

## Windows x64

Нужен Python 3.10+. Git, Rust и Visual Studio на целевом компьютере не требуются.
Полностью закройте обычный Horizon перед копированием ресурсов.
Откройте PowerShell в распакованной папке готовой сборки.

Сначала диагностика, которая ничего не запускает и не записывает:

```powershell
py -3 .\installed.py inspect --launcher "C:\Games\Horizon\horizon-launcher.exe"
```

Если лаунчер найден однозначно в стандартных папках или PATH, `--launcher`
можно опустить. Портативные установки в произвольном каталоге задаются явно.
Данные по умолчанию ищутся в `%APPDATA%\horizon-launcher`. Для другой папки
добавьте `--data "D:\HorizonData"`. Для выбора конкретной подготовленной
версии добавьте `--version ТЕГ`, как он называется в каталоге `versions`.

Установка отдельной сборки с повторным использованием копии ресурсов:

```powershell
py -3 .\installed.py install --launcher "C:\Games\Horizon\horizon-launcher.exe" --bundle . --target "$env:LOCALAPPDATA\HorizonEly" --experimental
```

`--target` должен указывать на новый каталог. При существующем каталоге
операция завершается отказом. Проверяются ОС, архитектура, SHA-256 файлов
готового пакета, маркеры интеграции, наличие подготовленной версии и свободное
место. SHA-256 в BUNDLE.json защищает от повреждения и случайного смешивания
файлов, но не заменяет цифровую подпись издателя: скачивайте пакет из своего
доверенного репозитория. Номер установленного лаунчера не угадывается по имени
файла; диагностика сообщает его хеш и версию игры из данных установки.

После установки запускайте `Start-HorizonEly.cmd` из нового каталога.
Он задаёт отдельные каталоги аккаунтов/настроек и игры. Для локального профиля:

```powershell
& "$env:LOCALAPPDATA\HorizonEly\Start-HorizonEly.cmd" account offline Friend_1
```

Затем откройте этот же `Start-HorizonEly.cmd` двойным щелчком.
Прямой запуск `horizon-launcher.exe` не использует каталоги, заданные оболочкой.

**Это экспериментальный путь.** Наличие каталога ресурсов Minecraft 26.3
не доказывает совместимость внутренних форматов со старой базой клиента.
Поэтому требуется явный `--experimental`. Проверки запуска игры, рендеринга
и настоящего входа Ely.by остаются необходимыми до выпуска стабильного релиза.

## Linux и macOS

Используйте нативный артефакт для своей ОС/архитектуры и Python 3.10+:

```bash
python3 installed.py inspect --launcher /полный/путь/horizon-launcher
python3 installed.py install --launcher /полный/путь/horizon-launcher --bundle . --target "$HOME/HorizonEly" --experimental
```

Для macOS `--launcher` может указывать на
`/Applications/Horizon.app/Contents/MacOS/horizon-launcher`.
Создаётся `Start-HorizonEly.command`; для Linux — `Start-HorizonEly.sh`.
Подписанный `.app` обычного Horizon не изменяется. Новая сборка не подписана
и не нотарифицирована; полноценного установщика macOS здесь нет.

## Откат

Полностью закройте новую сборку и выполните:

```powershell
py -3 .\installed.py rollback --target "$env:LOCALAPPDATA\HorizonEly"
```

Можно использовать `installed.py` из исходного распакованного артефакта.
Удаляются только файлы программ и оболочки, записанные в INSTALL_STATE.json.
Если их содержимое изменено после установки, откат останавливается.
Каталоги `launcher-data` и `game`, включая новые миры, остаются сохранены.
Для обычного Horizon достаточно снова запустить исходный лаунчер.

Установщик не читает и не копирует токены/ключницы и не запускает проверяемые
исполняемые файлы. Он не включает отсутствующие игровые ресурсы и не добавляет
протокол Ely.by внутрь произвольного официального бинарного файла.
